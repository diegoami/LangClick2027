# Langclick — Roadmap

Ukrainian comes first, as a companion to the source material: study eMova's course,
then practise and repeat here, which eMova doesn't offer. Other languages follow
v1.0.0. Audience size is not a goal.

## Status

**[v0.1.0](https://github.com/diegoami/LangClick2027/releases/tag/v0.1.0) is released.**
The owner's early view of its question, whether a table of cells works as the map:
"promising".

**v0.2.0 is in progress** ([proposal #3](https://github.com/diegoami/LangClick2027/issues/3)).
Built: the pack layout, comparison and explanation languages, IPA and cognates, concepts,
study links, Review, and the phonetics module for eMova lessons 1–3. Separate downloads
follow in v0.3.0 ([proposal #6](https://github.com/diegoami/LangClick2027/issues/6)).

## Milestones

| Milestone | Delivers |
|---|---|
| v0.1.0 | Ukrainian, 3 units (alphabet, one noun case table, one vocabulary set), with Overview, Known, drag quiz and saved progress |
| v0.2.0 | Study links and tracking, a Review screen; comparison with Russian or Polish, concepts, IPA, cognates; a phonetics module covering eMova lessons 1–3; the pack file layout that downloads will use |
| v0.3.0 | Separate downloads: a `langclick-packs` repo, a catalog, a Library screen. The app stops bundling content |
| v0.4.0 | Native audio as separate per-unit assets, guided lessons (Tour), first video through `ai-player` |
| v0.5.0 | Correspondence boards, false friends, multiple choice and typed answers, Windows and Android builds |
| v0.6+ | eMova lessons 4–27 in batches, each its own pack release, tracked by a coverage ledger |
| v1.0.0 | The whole 27-lesson course covered, compared with Russian and with Polish |
| Afterwards | eMova's B1 course, then other languages: Swedish, Japanese and more |

A later milestone gets its scope settled in its own proposal.
